# AURELIA — Luxury 3D Interior Architecture & Decor Atelier

A world-class, premium 3D home decor and interior architecture website built with **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS**, **Three.js**, **React Three Fiber (R3F)**, **Drei**, **GSAP (ScrollTrigger)**, and **Motion**.

---

## ✨ Features & 3D Interactive Highlights

- **Asset A: Interactive 3D Hero Furniture:**
  - Real-time 3D Lounge Chair and Velvet Curved Sofa toggle with PBR materials, warm architectural illumination, and mouse parallax camera movement.
- **Asset B: 3D Decorative Objects Atelier:**
  - Individual 3D decorative objects (`Vessel No. VII`, `Lanterne Brutaliste`, `Infinitum Ribbon Sculpture`, `Travertine Monolith Table`) with organic levitation and 360° inspection.
- **Asset C: Signature Spaces 3D Room Tour:**
  - Multi-element interior scene with GSAP ScrollTrigger camera director gliding smoothly across curated architectural viewpoints.
- **Asset D: 3D Material Craftsmanship:**
  - Physically based PBR material orb showcasing vein-cut Roman travertine, Canaletto walnut, alpine bouclé, brushed antique brass, chalk feldspar ceramics, and unbleached Belgian linen.
- **Puture-Style 3D Layer Architecture:**
  - Deconstructed Spatial Anatomy stack featuring 5 exploded isometric 3D tiers with continuous floating waves, scroll-driven SVG vector path drawing, and pop-to-front 3D inspection.
- **Atmospheric 3D Lighting Chamber:**
  - Real-time daylight progression and circadian Kelvin temperature simulator (Dawn 6500K, Golden Hour 3000K, Candlelight 2200K, Nocturne 2700K) with interactive 360° sun azimuth slider.
- **Curated Haute Decor Collection:**
  - 6 bespoke 3D products with full 3D quick-inspect modals, 360° orbit, and material finish customizers.
- **All Inner Pages Equipped with 3D Assets:**
  - `/about`: Real-time 3D sculpture pedestal.
  - `/services`: Interactive 3D furniture fabrication workbench with wireframe toggle.
  - `/projects`: Curated architectural monograph with 3D tilt cards.
  - `/spaces`: Full 3D interior walkthrough & acoustic matrix.
  - `/contact`: Interactive 3D global horizon gyroscope.
- **Architectural Page Preloader:**
  - Precision chronometer dial gauge with 36 staggered tick marks and 360° synchronized needle rotation.

## 🛠 Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **3D Engine:** Three.js, React Three Fiber, @react-three/drei
- **Motion & Scroll:** GSAP, ScrollTrigger, Framer Motion
- **Icons:** Lucide React

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/MuzammalKhalil/AURELIA.git
   cd AURELIA
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   npm run start
   ```

Open [http://localhost:3001](http://localhost:3001) in your browser.
